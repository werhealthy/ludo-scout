# Ludo Scout 5.11.29 — Vinted local batch

- Aggiunge **Ottimizza** in Attività: passaggio locale esplicito, senza richieste Vinted, per ripulire il backlog, inferire lingua dai dati già catturati e normalizzare la coda prima del linking remoto.
- L'Accessibility Service prova ora a catturare **item ID / URL Vinted direttamente durante lo scroll** quando la UI espone letteralmente un URL o un token `/items/<id>`. Nessun numero viene indovinato da resource id, posizione RecyclerView o uniqueId.
- Se URL/ID vengono catturati dalla card, Ludo collega subito l'osservazione senza ricerca catalogo; l'eventuale data di pubblicazione resta un metadata pass a bassa priorità.
- Mantiene il linking remoto in finestre piccole e per gioco, così le osservazioni differite non diventano migliaia di job HTTP simultanei.
- Attività distingue rete, da collegare, locali e manuali e offre un batch locale volontario per grandi backlog.

## Nota tecnica
Il batch locale non può inventare un Vinted item ID che l'app Vinted non espone. Quando l'ID non è disponibile nella Accessibility tree, il collegamento remoto resta necessario, ma avviene dopo il filtro locale e con la cache/batching già esistenti.
