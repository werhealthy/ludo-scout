# Ludo Scout 5.12.2 — Engine run state

This patch fixes the engine state model before the next visual redesign.

- One ordinary scroll run owns the automatic backlog lane at a time.
- Newer scrolls are captured but remain waiting until the older run has finished automatic work.
- LIVE_DEAL, HUNT_PRIORITY and MANUAL_PRIORITY remain allowed to preempt the ordinary run.
- The production cached batch linker and deferred Vinted promoter are scoped to the active run.
- Deferred deterministic misses in the active run are retried once, then become explicit manual review instead of silently sleeping for 24h.
- Vinted manual-review items have a durable `manual_review_required` flag. Opening/exploring or retrying does not dismiss them.
- A review disappears only after explicit link resolution, archive/removal, or successful automatic resolution.
- Engine “ready” now means Vinted core identity plus completion of the normal deep-metadata attempt (`enrichment_state=COMPLETE`), so the UI does not call a card ready while its normal metadata step is still open.
- Completion notifications are emitted in run order; a newer scroll cannot announce completion before an older unfinished run.
- Motore overview focuses the oldest unfinished run and reports newer scrolls as waiting.

No additional network mechanism was introduced by this patch.
