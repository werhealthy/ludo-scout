# Ludo Scout 5.12.0 — UX Phase 1

This build changes information architecture without changing the engine logic validated in 5.11.30.

## Primary navigation
- Scopri
- Catalogo
- Motore
- Bundle
- Libreria

`Database` is no longer a top-level destination. It is exposed as `Giochi` from Catalogo.

## Motore
`Attività` becomes a product-facing engine dashboard:
- global status hero
- Vinted / BGG lane summaries
- today metrics
- separate drill-down for work in progress
- separate manual-review area
- recent observation sessions
- session history

Technical diagnostics move under Settings.

## Observation sessions
Observations are grouped locally into human-readable sessions when bursts are separated by at least 25 minutes. Opening a session filters Catalogo to listings observed during that session when those listings are present in the saved catalog.

No network requests are added by this UX feature.
