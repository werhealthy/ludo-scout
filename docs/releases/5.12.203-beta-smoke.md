## Acceptance gates

The beta APK must compile on the owner's Windows machine, report the exact package/version, and be signed by the pinned certificate. Before any installation, confirm exactly one authorized Android device, the previously installed app package and its versionCode **lower** than the candidate. Use `adb install -r` only (retain app data, never uninstall, clear storage or downgrade). Verify the version installed afterward and confirm the user's favorites, Ludo memories, catalog and database remain present on device.

The project's hosted GitHub Actions / Cloudflare budget is unavailable according to `STATE.md`. A candidate PR and static source check are **not** proof of a native build, APK signing, device installation, Firebase App Distribution upload, or tester delivery. The beta Firebase workflow still needs its secret account credentials and tester list; do not describe the beta as distributed unless that upload is verified. A local Windows smoke installation is an initial development deploy, **not** autonomous deployment from Telegram.

Local `tools/verify_beta_smoke_windows.ps1` is an opt-in, one-shot, repo- and commit-pinned build/verify/install helper. It uses a detached temporary Git worktree without changing the owner's current checkout. It preserves the verified APK outside the repository. Installation requires an explicit `-Install` switch and fails closed on version or certificate mismatch.
