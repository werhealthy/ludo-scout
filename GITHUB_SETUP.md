# First GitHub setup — Ludo Scout

## 1. Permanent folder
Extract this project to a stable path, for example:
`D:\Dev\LudoScout`

Do not keep the canonical project in Downloads.

## 2. BGG token — one-time local setup
Open this file on Windows (create the folder/file if missing):
`C:\Users\<YOUR_WINDOWS_USER>\.gradle\gradle.properties`

Add one line:
`BGG_TOKEN=YOUR_REAL_TOKEN`

Do not put the real value in `secrets.properties`, GitHub, screenshots or chat.

## 3. Preserve current Android signing key BEFORE CI
Because this project currently uses Android's default debug signing for debug builds, first locate:
`C:\Users\<YOUR_WINDOWS_USER>\.android\debug.keystore`

Do not upload this file to the repository and do not send it in chat.
We will later encode it locally and store it as a GitHub Actions Secret so cloud builds can update the already-installed app.

## 4. GitHub repository
Create a private repository named `ludo-scout` with no README, .gitignore or license generated by GitHub.

## 5. GitHub Desktop
Use `File -> Add local repository` / `Create a repository from existing project` for the permanent `D:\Dev\LudoScout` folder.
Create the initial commit and publish it to the private `ludo-scout` repository.

## 6. Branches
Keep `main` as the initial/stable baseline, then create `beta` from `main`.
Normal development and automated phone builds will target `beta`.

## 7. Do NOT enable automated APK delivery yet
First preserve/verify signing. Then we will add GitHub Actions, GitHub Secrets and Firebase App Distribution.
